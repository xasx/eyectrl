A 120 px square tile with a 60 px-radius circular dwell target inscribed in it. Square 14 400 px², circle 11 310 px² — 3 090 px², 21.5%, is drawn but dead. Aim at a corner and nothing happens, with no way to tell why.
Proposed — the drawing is the hit test
Same 120 px footprint, same 24 px clearance, same dwell radius — drawn as the disc it already is. Zero dead pixels, and the gap between neighbours now reads as a gap rather than as more button.
Contrast ratios are computed from the Midnight token hex values in MidnightTheme.cs by the WCAG relative-luminance formula, not measured on a display. SurfaceDark and SurfaceMedium ship at 0xFA alpha and composite over live desktop content, which the theme spec bounds at −5% worst case. Tokens.CornerRadiusCircle (9999) already exists, so the disc needs no new token — but check the corner-radius ratchet in App.Tests before writing one in EyeCtrl.Controls.
