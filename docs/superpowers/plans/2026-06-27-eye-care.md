# Eye-Care Fatigue Countermeasure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a hybrid eye-fatigue countermeasure to EyeCtrl — a gaze-aware scheduler surfaces a dwellable top-edge banner, and on accept runs a short gaze-tracked exercise, ending with a summary card.

**Architecture:** All novel domain logic (scheduler, fatigue monitor, exercises, scoring) lives in a new `net10.0` leaf project `EyeCtrl.EyeCare` that references `EyeCtrl.Core` (mirrors the `EyeCtrl.LM` pattern). WPF overlays and a hooks bridge live in `EyeCtrl.App`. `IEyeCareHooks` in Core is the plugin seam. `GazeEngine` gains one additive `GazeSampled` event carrying the raw `GazePoint` (with `IsValid`); the existing `CursorMoved` is insufficient for away-detection.

**Tech Stack:** .NET 10 (net10.0 for EyeCare + tests; net10.0-windows for App/overlays), WPF, CommunityToolkit.Mvvm (`[ObservableProperty]`), xUnit v3, NFluent 3.1.0, BenchmarkDotNet (none here). TDD throughout — every domain unit gets a failing test first.

**Reference spec:** `docs/superpowers/specs/2026-06-27-eye-care-design.md`

## Conventions Reference (read before starting)

These are the codebase patterns every task follows. Refer back here rather than re-deriving.

- **File-scoped namespaces**, **Allman braces**, fields `_camelCase`, nullable enabled, `var` for obvious types, **no `#region`**.
- **Settings class shape** (`src/EyeCtrl.Core/Settings/DwellSettings.cs` is the canonical example): `public partial class XxxSettings : ObservableObject, IValidatable`, each field `[ObservableProperty] private T _camel = default;`, range validation via `ValidationHelper.ValidateRange(...)` collected in `Validate()` with `ValidationHelper.CollectErrors(...)`.
- **Time:** all gaze timestamps are **microseconds** (`long`). ms→µs via `MathConstants.MicrosecondsPerMillisecond` (= 1000L). No `Task.Delay` in domain logic — drive everything off `Update(timestampUs)`.
- **Coordinates:** `PhysicalPoint` (in `EyeCtrl.Core.Models`), physical screen pixels. Tests work in arbitrary pixel units.
- **Tests:** xUnit v3 (`[Fact]`), NFluent (`Check.That(x).IsEqualTo(y)`), **private nested fakes, no mocking libs**. Test class = `XxxTests`, methods `_`-separated PascalCase. Namespace mirrors source (`EyeCtrl.EyeCare.Tests.Exercises` etc.). `OutputType=Exe` (set by `tests/Directory.Build.props`).
- **`GazePoint` record:** `(double X, double Y, long TimestampMicroseconds, bool IsValid)`.
- **Build/test commands:** `dotnet build EyeCtrl.slnx`; `dotnet test tests/EyeCtrl.EyeCare.Tests`; full headless run `dotnet test --filter "Category!=UI"`.

```csharp
namespace EyeCtrl.EyeCare.Scoring;

using EyeCtrl.Core.Models;

/// <summary>Accumulates per-frame gaze-vs-target deltas, then computes an <see cref="ExerciseResult"/>.</summary>
public class ExerciseMetrics
{
    private readonly List<(double dx, double dy)> _deltas = new();
    private readonly List<long> _reactionTimesUs = new();

    /// <summary>Records one gaze-vs-target sample pair.</summary>
    public void RecordDelta(PhysicalPoint gaze, PhysicalPoint target)
    {
        _deltas.Add((gaze.X - target.X, gaze.Y - target.Y));
    }

    /// <summary>Records one reaction-time sample (microseconds from target appearance to gaze acquisition).</summary>
    public void RecordReactionTime(long latencyMicroseconds) => _reactionTimesUs.Add(latencyMicroseconds);

    /// <summary>Mean accuracy 0–100: the percentage of samples within the on-target radius.</summary>
    public double ComputeAccuracyPercent(double onTargetRadiusPixels)
    {
        if (_deltas.Count == 0) return 0;
        var rSq = onTargetRadiusPixels * onTargetRadiusPixels;
        var onTarget = _deltas.Count(d => (d.dx * d.dx + d.dy * d.dy) <= rSq);
        return 100.0 * onTarget / _deltas.Count;
    }

    /// <summary>Steadiness 0–5: lower gaze-to-target distance variance ⇒ steadier.</summary>
    public double ComputeSteadiness0To5()
    {
        if (_deltas.Count < 2) return 0;
        var mean = _deltas.Average(d => Math.Sqrt(d.dx * d.dx + d.dy * d.dy));
        // Map: 0px mean error → 5.0; 100px mean error → 0.0 (clamped). Tunable.
        var score = 5.0 * (1.0 - Math.Clamp(mean / 100.0, 0.0, 1.0));
        return score;
    }

    /// <summary>Mean reaction time in ms, or null if none recorded.</summary>
    public double? ComputeReactionTimeMs()
    {
        if (_reactionTimesUs.Count == 0) return null;
        return _reactionTimesUs.Average(us => us / 1000.0);
    }

    /// <summary>Number of recorded gaze samples.</summary>
    public int SampleCount => _deltas.Count;
}
```

```csharp
namespace EyeCtrl.EyeCare.Exercises;

using EyeCtrl.Core.Models;
using EyeCtrl.EyeCare.Scoring;

/// <summary>Shared base: gaze-sample buffering against a moving target, accuracy/steadiness math.</summary>
public abstract class ExerciseBase : IExercise
{
    private readonly ExerciseMetrics _metrics = new();
    private long? _firstTimestampUs;
    private long? _lastTimestampUs;

    /// <inheritdoc />
    public abstract string Name { get; }

    /// <inheritdoc />
    public abstract double OnTargetRadiusPixels { get; }

    /// <summary>The configured exercise duration in microseconds.</summary>
    protected long DurationMicroseconds { get; init; }

    /// <inheritdoc />
    public abstract PhysicalPoint GetTargetAt(long timestampMicroseconds);

    /// <inheritdoc />
    public virtual void RecordGaze(PhysicalPoint gaze, long timestampMicroseconds)
    {
        _firstTimestampUs ??= timestampMicroseconds;
        _lastTimestampUs = timestampMicroseconds;
        _metrics.RecordDelta(gaze, GetTargetAt(timestampMicroseconds));
    }

    /// <summary>Records a reaction-time sample (saccade exercises only).</summary>
    protected void RecordReactionTime(long latencyMicroseconds) => _metrics.RecordReactionTime(latencyMicroseconds);

    /// <summary>Builds the result using the shared metrics + the exercise's own encouragement line.</summary>
    protected ExerciseResult BuildResult(double? reactionTimeOverride = null)
    {
        var durationSec = (_lastTimestampUs - _firstTimestampUs) / 1000.0;
        var rt = reactionTimeOverride ?? _metrics.ComputeReactionTimeMs();
        return new ExerciseResult(
            ExerciseName: Name,
            AccuracyPercent: _metrics.ComputeAccuracyPercent(OnTargetRadiusPixels),
            Steadiness0To5: _metrics.ComputeSteadiness0To5(),
            ReactionTimeMs: rt,
            DurationSeconds: durationSec,
            EncouragementLine: EncouragementLine);
    }

    /// <summary>Short encouraging line for the summary card. Override per exercise.</summary>
    protected abstract string EncouragementLine { get; }

    /// <inheritdoc />
    public abstract ExerciseResult Complete();
}
```

```csharp
namespace EyeCtrl.EyeCare.Exercises;

using EyeCtrl.Core;
using EyeCtrl.Core.Models;
using EyeCtrl.EyeCare.Scoring;

/// <summary>Exercise 2: smooth pursuit. Round 1 = circle orbit; round 2 = figure-8 (lemniscate).</summary>
public sealed class SmoothPursuitExercise : ExerciseBase
{
    private readonly PhysicalPoint _center;
    private readonly double _radius;
    private readonly long _periodMicroseconds;

    /// <summary>Creates the exercise.</summary>
    /// <param name="center">Orbit center (physical px).</param>
    /// <param name="radius">Orbit radius (px).</param>
    /// <param name="periodMs">Seconds per full revolution.</param>
    /// <param name="onTargetRadiusPixels">On-target scoring radius.</param>
    public SmoothPursuitExercise(PhysicalPoint center, double radius, int periodMs, double onTargetRadiusPixels)
    {
        _center = center;
        _radius = radius;
        _periodMicroseconds = periodMs * MathConstants.MicrosecondsPerMillisecond;
        OnTargetRadiusPixels = onTargetRadiusPixels;
    }

    public override string Name => "Smooth Pursuit";
    public override double OnTargetRadiusPixels { get; }
    protected override string EncouragementLine => "Smooth tracking!";

    public override PhysicalPoint GetTargetAt(long timestampMicroseconds)
    {
        var period = _periodMicroseconds;
        var revolutions = (double)timestampMicroseconds / period;
        var theta = 2.0 * Math.PI * revolutions;

        // First half of the exercise: circle. Second half: figure-8 (lemniscate of Gerono).
        bool isFigure8 = revolutions >= 1.0;
        if (!isFigure8)
        {
            return new PhysicalPoint(
                _center.X + _radius * Math.Cos(theta),
                _center.Y + _radius * Math.Sin(theta));
        }
        else
        {
            // Lemniscate: x = a*cos(t), y = a*sin(t)*cos(t)
            var tt = theta - 2.0 * Math.PI; // continue phase from where circle ended
            return new PhysicalPoint(
                _center.X + _radius * Math.Cos(tt),
                _center.Y + (_radius * 0.5) * Math.Sin(2.0 * tt));
        }
    }

    public override ExerciseResult Complete() => BuildResult();
}
```

```csharp
namespace EyeCtrl.EyeCare.Exercises;

using EyeCtrl.Core;
using EyeCtrl.Core.Models;
using EyeCtrl.EyeCare.Scoring;

/// <summary>Exercise 4: saccade jumps. One target lights at a time; user snaps gaze to it.
/// Score: saccade latency (reaction time from target appearance to gaze acquisition).</summary>
public sealed class SaccadeExercise : ExerciseBase
{
    private readonly PhysicalPoint[] _targets;
    private readonly long _dwellPerTargetMicroseconds;
    private long? _currentTargetStartUs;
    private bool _acquiredThisTarget;

    public SaccadeExercise(PhysicalPoint[] targets, int dwellPerTargetMs, double onTargetRadiusPixels)
    {
        _targets = targets;
        _dwellPerTargetMicroseconds = dwellPerTargetMs * MathConstants.MicrosecondsPerMillisecond;
        OnTargetRadiusPixels = onTargetRadiusPixels;
    }

    public override string Name => "Saccade Jumps";
    public override double OnTargetRadiusPixels { get; }
    protected override string EncouragementLine => "Quick eyes!";

    public override PhysicalPoint GetTargetAt(long timestampMicroseconds)
    {
        var index = (int)(timestampMicroseconds / _dwellPerTargetMicroseconds);
        return _targets[index % _targets.Length];
    }

    public override void RecordGaze(PhysicalPoint gaze, long timestampMicroseconds)
    {
        // Track first + last timestamps for duration (base handles accuracy deltas)
        base.RecordGaze(gaze, timestampMicroseconds);

        var target = GetTargetAt(timestampMicroseconds);
        var targetStart = (timestampMicroseconds / _dwellPerTargetMicroseconds) * _dwellPerTargetMicroseconds;

        if (_currentTargetStartUs != targetStart)
        {
            _currentTargetStartUs = targetStart;
            _acquiredThisTarget = false;
        }

        // On-target acquisition: record latency once per target
        if (!_acquiredThisTarget)
        {
            var dx = gaze.X - target.X;
            var dy = gaze.Y - target.Y;
            if ((dx * dx + dy * dy) <= OnTargetRadiusPixels * OnTargetRadiusPixels)
            {
                var latency = timestampMicroseconds - targetStart;
                if (latency > 0)
                    RecordReactionTime(latency);
                _acquiredThisTarget = true;
            }
        }
    }

    public override ExerciseResult Complete() => BuildResult();
}
```

```csharp
        _bottomRight = bottomRight;

    public override double OnTargetRadiusPixels { get; }
    protected override string EncouragementLine => "Full range of motion!";

        var leg = (int)(timestampMicroseconds / _sweepMicroseconds);
        var frac = (double)(timestampMicroseconds % _sweepMicroseconds) / _sweepMicroseconds;
        // ping-pong within a leg for a smooth there-and-back
        if (frac > 0.5) frac = (1.0 - frac) * 2.0; else frac *= 2.0;

        var x = _topLeft.X + (_bottomRight.X - _topLeft.X) * frac;
        var y = _topLeft.Y + (_bottomRight.Y - _topLeft.Y) * frac;

        return leg % 3 switch
        {
            0 => new PhysicalPoint(x, _topLeft.Y),                 // horizontal
            1 => new PhysicalPoint(_topLeft.X, y),                 // vertical
            _ => new PhysicalPoint(x, y),                          // diagonal
        };
    }

    public override ExerciseResult Complete() => BuildResult();
```

```csharp
using EyeCtrl.EyeCare.Exercises;

/// <summary>Owns round-robin exercise selection (never the same twice in a row).</summary>
public sealed class ExerciseRunner
{
    private readonly IExercise[] _pool;
    private readonly Random _rng;
    private int _lastIndex = -1;

    /// <param name="pool">The exercise pool to rotate through.</param>
    /// <param name="seed">Seed for deterministic selection (tests).</param>
    public ExerciseRunner(IExercise[] pool, int seed)
    {
        _pool = pool;
        _rng = new Random(seed);
    }

    /// <summary>Returns an exercise, never the same as the previous call.</summary>
    public IExercise NextExercise()
    {
        if (_pool.Length == 1) return _pool[0];

        int idx;
        do { idx = _rng.Next(_pool.Length); } while (idx == _lastIndex);
        _lastIndex = idx;
        return _pool[idx];
    }
}
```

```csharp
namespace EyeCtrl.EyeCare;

using EyeCtrl.Core.Models;
using EyeCtrl.Core.Settings;

/// <summary>Rolling fatigue score from gaze samples. Derives fixation/saccade structure from
/// raw positions (does NOT depend on GazeEngine's private FixationDetector). Gated off by default.</summary>
public sealed class FatigueMonitor
{
    private readonly EyeCareSettings _settings;
    private readonly double _fixationRadiusPixels;
    private readonly long _windowMicroseconds;
    private readonly Queue<(long ts, double x, double y)> _samples = new();

    public FatigueMonitor(EyeCareSettings settings, double fixationRadiusPixels, int windowSeconds)
    {
        _settings = settings;
        _fixationRadiusPixels = fixationRadiusPixels;
        _windowMicroseconds = windowSeconds * 1_000_000L;
        Score = 0.0;
    }

    /// <summary>Current 0.0–1.0 fatigue score.</summary>
    public double Score { get; private set; }

    /// <summary>Feeds one raw gaze sample.</summary>
    public void OnSample(GazePoint sample)
    {
        if (!_settings.FatigueMonitorEnabled || !sample.IsValid)
        {
            Score = 0.0;
            return;
        }

        _samples.Enqueue((sample.TimestampMicroseconds, sample.X, sample.Y));
        // Evict samples outside the window
        var cutoff = sample.TimestampMicroseconds - _windowMicroseconds;
        while (_samples.Count > 0 && _samples.Peek().ts < cutoff)
            _samples.Dequeue();

        if (_samples.Count < 2) { Score = 0.0; return; }

        // ── Signal 1: sustained-fixation ratio ──
        // % of samples within _fixationRadiusPixels of the window centroid.
        var arr = _samples.ToArray();
        var cx = arr.Average(s => s.x);
        var cy = arr.Average(s => s.y);
        var rSq = _fixationRadiusPixels * _fixationRadiusPixels;
        var inFixation = arr.Count(s => ((s.x - cx) * (s.x - cx) + (s.y - cy) * (s.y - cy)) <= rSq);
        var fixationRatio = (double)inFixation / arr.Length;

        // ── Signal 2: saccade-range shrink ──
        // Bounding-box area normalized; small box = eyes locked in.
        var minX = arr.Min(s => s.x); var maxX = arr.Max(s => s.x);
        var minY = arr.Min(s => s.y); var maxY = arr.Max(s => s.y);
        var boxArea = (maxX - minX) * (maxY - minY);
        // Normalize: assume a "healthy" box of ~1,000,000 sq px (1000x1000); shrink → higher score.
        var shrinkScore = 1.0 - Math.Clamp(boxArea / 1_000_000.0, 0.0, 1.0);

        // Weighted blend (fixation ratio weighted higher — more reliable signal).
        Score = Math.Clamp(0.7 * fixationRatio + 0.3 * shrinkScore, 0.0, 1.0);
    }

    /// <summary>Resets the monitor (call on break completion or settings toggle).</summary>
    public void Reset()
    {
        _samples.Clear();
        Score = 0.0;
    }
}
```

```csharp
namespace EyeCtrl.EyeCare;

using EyeCtrl.Core.Models;
using EyeCtrl.Core.Settings;

/// <summary>Trigger core: active-session clock + cadence + natural-break suppression.
/// Driven entirely by Update(timestampUs) — no timers, no Task.Delay → fully deterministic.</summary>
public sealed class EyeCareScheduler
{
    private readonly EyeCareSettings _settings;
    private long _activeMicroseconds;       // accumulated active gaze time
    private long _awayRunStartUs;            // start of current looking-away run (0 = not away)
    private bool _naturalBreakTakenThisInterval;

    public EyeCareScheduler(EyeCareSettings settings)
    {
        _settings = settings;
    }

    /// <summary>Raised when a break becomes due (caller then shows the banner via hooks).</summary>
    public event Action? BreakDue;

    /// <summary>Feeds one raw gaze sample + the current paused state.</summary>
    public void Update(GazePoint sample, bool isPaused)
    {
        if (!_settings.Enabled) return;

        // Advance the inter-sample baseline on EVERY call (valid, invalid, paused).
        // Computing the step here — before any early return — means an away/paused gap
        // moves the baseline forward instead of being added to the active total on the
        // first sample after the gap (which would over-count away/paused time).
        var step = ComputeStepMicroseconds(sample.TimestampMicroseconds);

        // ── Track looking-away runs for natural-break suppression ──
        if (!sample.IsValid)
        {
            if (_awayRunStartUs == 0) _awayRunStartUs = sample.TimestampMicroseconds;
            var awayFor = sample.TimestampMicroseconds - _awayRunStartUs;
            if (awayFor >= _settings.NaturalBreakSeconds * 1_000_000L)
                _naturalBreakTakenThisInterval = true;
            return; // away time does NOT accrue (baseline already advanced above)
        }

        // Eyes back; reset away-run tracking
        _awayRunStartUs = 0;

        if (isPaused) return; // paused → no active time accrues (baseline already advanced)

        _activeMicroseconds += step;

        var intervalUs = _settings.IntervalMinutes * 60_000_000L;
        if (_activeMicroseconds >= intervalUs)
        {
            if (!_naturalBreakTakenThisInterval)
                BreakDue?.Invoke();
            // Reset for the next interval regardless
            _activeMicroseconds = 0;
            _naturalBreakTakenThisInterval = false;
        }
    }

    private long? _lastTimestampUs;
    private long ComputeStepMicroseconds(long nowUs)
    {
        var step = (_lastTimestampUs is null) ? 0 : (nowUs - _lastTimestampUs.Value);
        _lastTimestampUs = nowUs;
        return Math.Max(0, step);
    }

    /// <summary>Applies a snooze (caller invokes after the user dismisses the banner).</summary>
    public void Snooze()
    {
        _activeMicroseconds = -_settings.SnoozeMinutes * 60_000_000L;
        _naturalBreakTakenThisInterval = false;
    }

    /// <summary>Resets after a completed break.</summary>
    public void OnBreakCompleted()
    {
        _activeMicroseconds = 0;
        _naturalBreakTakenThisInterval = false;
    }
}
```

```csharp
namespace EyeCtrl.EyeCare;

using EyeCtrl.Core.Interfaces;
using EyeCtrl.Core.Models;
using EyeCtrl.EyeCare.Exercises;
using EyeCtrl.EyeCare.Scoring;
using EyeCtrl.Core.Settings;

/// <summary>Orchestrator: subscribes to gaze, owns scheduler + fatigue monitor, drives hooks.
/// In v1 this is the single entry point; it is constructed by AppBootstrapper and fed by
/// EventCoordinator wiring GazeEngine.GazeSampled → OnGazeSample.</summary>
public sealed class EyeCareService : IEyeCareService
{
    private readonly EyeCareSettings _settings;
    private readonly EyeCareScheduler _scheduler;
    private readonly FatigueMonitor _fatigueMonitor;
    private readonly ExerciseRunner _runner;
    private readonly IEyeCareHooks _hooks;
    private readonly PhysicalPoint _screenCenter;
    private bool _busy; // true while banner/exercise/summary is on screen

    public EyeCareService(
        EyeCareSettings settings,
        ExerciseRunner runner,
        IEyeCareHooks hooks,
        PhysicalPoint screenCenter,
        double fixationRadiusPixels = 50,
        int fatigueWindowSeconds = 60)
    {
        _settings = settings;
        _scheduler = new EyeCareScheduler(settings);
        _fatigueMonitor = new FatigueMonitor(settings, fixationRadiusPixels, fatigueWindowSeconds);
        _runner = runner;
        _hooks = hooks;
        _screenCenter = screenCenter;
        _scheduler.BreakDue += OnBreakDue;
    }

    /// <inheritdoc />
    public void OnGazeSample(GazePoint sample, bool isPaused)
    {
        if (!_settings.Enabled) return;
        _fatigueMonitor.OnSample(sample);
        _scheduler.Update(sample, isPaused);

        // Escalation (gated): if fatigue crosses threshold before the cadence timer, fire early.
        if (_settings.FatigueMonitorEnabled && !_busy && _fatigueMonitor.Score >= _settings.FatigueThreshold)
        {
            // Fire only if we're also close enough to the interval that an early break is reasonable.
            // (Keeps the heuristic from firing every few minutes.)
            OnBreakDue();
        }
    }

    /// <inheritdoc />
    public void Cancel()
    {
        _busy = false;
        _scheduler.OnBreakCompleted();
    }

    // async void is required (event-handler signature for EyeCareScheduler.BreakDue).
    // It MUST swallow exceptions: an unobserved throw from an async void crashes the process.
    private async void OnBreakDue()
    {
        if (_busy) return;
        _busy = true;
        try
        {
            var accepted = await _hooks.ShowBannerAsync("Time for an eye break");
            if (!accepted)
            {
                _scheduler.Snooze();
                return;
            }

            var exercise = _runner.NextExercise();
            var durationUs = _settings.ExerciseDurationSeconds * 1_000_000L;
            var outcome = await _hooks.ShowExerciseAsync(
                exercise.Name, durationUs, exercise.GetTargetAt, exercise.RecordGaze);
            // Score from the exercise's own recorded samples, then show the summary.
            var result = exercise.Complete();
            var finalOutcome = new EyeCareExerciseOutcome(
                result.ExerciseName, result.AccuracyPercent, result.Steadiness0To5,
                result.ReactionTimeMs, result.DurationSeconds, result.EncouragementLine);
            await _hooks.ShowSummaryAsync(finalOutcome);
            _scheduler.OnBreakCompleted();
        }
        catch (Exception ex)
        {
            // Never let an overlay/UI failure escape an async void. Log + recover.
            System.Diagnostics.Debug.WriteLine($"[EyeCare] break flow failed: {ex}");
            _scheduler.OnBreakCompleted();
        }
        finally
        {
            _busy = false;
            _fatigueMonitor.Reset();
        }
    }
}
```

```csharp
        _startCenter = new PhysicalPoint(screenCenter.X * 2 - 60, 40);

        // DwellTarget ctor is (string id, PhysicalPoint center, double radius, int dwellTimeMs) — ms, not µs.
        _dwell.AddTarget(new DwellTarget("start", _startCenter, radius: 60, dwellTimeMs: _dwellMs));
        _dwell.AddTarget(new DwellTarget("snooze", _snoozeCenter, radius: 60, dwellTimeMs: _dwellMs));

        WorkDim.Visibility = Visibility.Visible;
```

```csharp
using EyeCtrl.Core.Interfaces;

/// <summary>App-side implementation of IEyeCareHooks. Bridges EyeCare logic to WPF overlays
/// and routes the live gaze stream into whichever eye-care overlay is currently active.</summary>
public sealed class EyeCareHooks : IEyeCareHooks
{
    private readonly Dispatcher _dispatcher;
    private readonly EyeCareBannerWindow _banner;
    private readonly PhysicalPoint _screenCenter;
    private readonly int _bannerAutoSnoozeSeconds;

    // While an overlay is on screen this points at its OnGaze; null otherwise.
    private Action<PhysicalPoint, long>? _gazeSink;

    public EyeCareHooks(
        IMessenger messenger,
        Dispatcher dispatcher,
        EyeCareBannerWindow banner,
        PhysicalPoint screenCenter,
        int bannerAutoSnoozeSeconds = 15)
    {
        _dispatcher = dispatcher;
        _banner = banner;
        _screenCenter = screenCenter;
        _bannerAutoSnoozeSeconds = bannerAutoSnoozeSeconds;

        // CRITICAL: route gaze to the active overlay. Without this the banner's dwell buttons
        // never receive gaze (only auto-snooze works) and the exercise records nothing (all-zero
        // scores). We reuse GazeCursorMovedMessage — the same UI-thread gaze stream the cursor,
        // toolbar, and manual-selection consume (marshalled to the UI thread by GazeEngineAdapter),
        // so the overlays are touched only on the UI thread.
        messenger.Register<GazeCursorMovedMessage>(this,
            (r, m) => _gazeSink?.Invoke(m.Position, m.TimestampMicroseconds));
    }

    /// <inheritdoc />
    public Task<bool> ShowBannerAsync(string message)
    {
        return _dispatcher.InvokeAsync(async () =>
        {
            _gazeSink = _banner.OnGaze;       // start feeding gaze to the banner's DwellDetector
            try { return await _banner.ShowAsync(message, _screenCenter, _bannerAutoSnoozeSeconds); }
            finally { _gazeSink = null; }     // stop feeding once dismissed
        }).Task.Unwrap();
    }

    /// <inheritdoc />
    public Task ShowExerciseAsync(
        string exerciseName, long durationMicroseconds,
        Func<long, PhysicalPoint> getTargetAt, Action<PhysicalPoint, long> recordGaze)
    {
        // Filled in Task 17 (sets _gazeSink to the exercise window's OnGaze).
        throw new NotImplementedException("Exercise window wired in Task 17");
    }

    /// <inheritdoc />
    public Task ShowSummaryAsync(EyeCareExerciseOutcome outcome)
    {
        // Filled in Task 18
        throw new NotImplementedException("Summary wired in Task 18");
    }
}
```

```csharp
namespace EyeCtrl.App.Overlays;

using System;
using System.Windows;
using System.Windows.Controls;
using System.Windows.Threading;
using EyeCtrl.Core;                 // MathConstants
using EyeCtrl.Core.Interfaces;     // EyeCareExerciseOutcome
using EyeCtrl.Core.Models;

public partial class EyeCareExerciseWindow : OverlayWindow
{
    private TaskCompletionSource<bool>? _runTcs;
    private DispatcherTimer? _frameTimer;
    private long _startUs;
    private long _durationUs;
    private Func<long, PhysicalPoint>? _getTargetAt;  // ELAPSED µs → target position
    private Action<PhysicalPoint, long>? _recordGaze;  // (gaze point, ELAPSED µs)

    public EyeCareExerciseWindow()
    {
        InitializeComponent();
        IsClickThrough = true;                 // set here, not in XAML (see banner note)
        SkipButton.Click += (_, _) => FinishRun();
    }

    // ONE wall clock for both the visible animation and gaze recording, so the dot the user
    // follows and the target used for scoring share a single 0-based elapsed timeline.
    // (.NET has no ToUnixTimeMicroseconds(); compose it from ms — same idiom as MouseGazeProvider.)
    private static long NowMicroseconds() =>
        DateTimeOffset.UtcNow.ToUnixTimeMilliseconds() * MathConstants.MicrosecondsPerMillisecond;

    /// <summary>Runs the moving-target animation for the duration; resolves when time elapses or
    /// the user skips. Scoring is the caller's job (via the recordGaze callback + IExercise.Complete).
    /// <paramref name="getTargetAt"/> takes ELAPSED µs (0-based) — exercises assume t starts at 0.</summary>
    public Task RunAsync(string exerciseName, long durationMicroseconds,
        Func<long, PhysicalPoint> getTargetAt, Action<PhysicalPoint, long> recordGaze)
    {
        _getTargetAt = getTargetAt;
        _recordGaze = recordGaze;
        _durationUs = durationMicroseconds;
        _startUs = NowMicroseconds();
        ExerciseName.Text = exerciseName;
        SummaryCard.Visibility = Visibility.Collapsed;
        Stage.Visibility = Visibility.Visible;
        Show();

        _runTcs = new TaskCompletionSource<bool>();
        _frameTimer = new DispatcherTimer(TimeSpan.FromMilliseconds(16), DispatcherPriority.Render, (_, _) =>
        {
            var elapsed = NowMicroseconds() - _startUs;        // 0-based elapsed, NOT absolute
            if (elapsed >= _durationUs) { FinishRun(); return; }

            var target = getTargetAt(elapsed);
            Canvas.SetLeft(TargetDot, target.X - TargetDot.Width / 2);
            Canvas.SetTop(TargetDot, target.Y - TargetDot.Height / 2);

            var remain = Math.Max(0, _durationUs - elapsed);
            Countdown.Text = $"00:{(int)(remain / 1_000_000):D2} / 00:{(int)(_durationUs / 1_000_000):D2}";
            Progress.Value = 100.0 * elapsed / _durationUs;
        }, Dispatcher);
        _frameTimer.Start();
        return _runTcs.Task;
    }

    /// <summary>Live gaze: move the green ring and record the sample against the target at the SAME
    /// wall-clock elapsed the animation uses. (The gaze stream's own timestamp is a different clock
    /// domain — tracker vs wall — so we recompute elapsed here rather than trust the incoming µs.)</summary>
    public void OnGaze(PhysicalPoint gaze, long timestampUs)
    {
        Canvas.SetLeft(GazeRing, gaze.X - GazeRing.Width / 2);
        Canvas.SetTop(GazeRing, gaze.Y - GazeRing.Height / 2);
        if (_runTcs is { Task.IsCompleted: false })
            _recordGaze?.Invoke(gaze, NowMicroseconds() - _startUs);
    }

    private void FinishRun()
    {
        _frameTimer?.Stop();
        _frameTimer = null;
        Stage.Visibility = Visibility.Collapsed;
        // Hand control back to EyeCareService, which scores (exercise.Complete) then calls ShowSummaryAsync.
        _runTcs?.TrySetResult(true);
        _runTcs = null;
    }

    /// <summary>Shows the summary card with the computed metrics for ~3s, then hides the window.</summary>
    public Task ShowSummaryAsync(EyeCareExerciseOutcome outcome)
    {
        SummaryName.Text = $"{outcome.ExerciseName} complete";
        SummaryAccuracy.Text = $"{outcome.AccuracyPercent:0}%";
        SummarySteadiness.Text = $"{outcome.Steadiness0To5:0.0}";
        SummaryEncourage.Text = outcome.EncouragementLine;
        SummaryCard.Visibility = Visibility.Visible;

        var tcs = new TaskCompletionSource<bool>();
        var timer = new DispatcherTimer(TimeSpan.FromSeconds(3), DispatcherPriority.Normal, (s, _) =>
        {
            ((DispatcherTimer)s!).Stop();
            SummaryCard.Visibility = Visibility.Collapsed;
            Hide();
            tcs.TrySetResult(true);
        }, Dispatcher);
        timer.Start();
        return tcs.Task;
    }
}
```

> **Note — skip button & click-through.** The window is click-through (gaze app; we don't want clicks reaching apps behind the dimmed overlay), so `SkipButton.Click` only fires for a real mouse — useful for desk testing but not for a pure-gaze user. Making Skip a dwell target is a v1.1 refinement; the exercise also ends on its own when the duration elapses, so a gaze user is never stuck.

**Gaps found and addressed during design review:**
- **Circular dep (Core ↔ EyeCare):** `EyeCareSettings` is created **directly in `EyeCtrl.Core/Settings/`** (Task 1) since `EyeCtrlSettings` (Core) hosts it and uses only Core types — no move, no circular reference. `IEyeCareHooks` uses **Core-only types** with a Core-side `EyeCareExerciseOutcome` mirror (Task 14). `IExercise`/scoring stays in EyeCare; hooks exchange primitives + callbacks.
- **Exercise window needs real IExercise but hooks seam can't see it:** resolved by passing `getTargetAt`/`recordGaze` callbacks through the hooks (Task 14 interface) — the service owns the real `IExercise`.

**Findings fixed in a second review pass (App-integration APIs verified against source):**
- **Gaze was never routed to the overlays** (banner dwell + exercise scoring would be dead): `EyeCareHooks` now registers for `GazeCursorMovedMessage` and routes it to the active overlay's `OnGaze` via a `_gazeSink` (Tasks 16/17). Documented as the two intentional gaze paths in Task 19.
- **`DwellTarget` ctor** is `(id, center, radius, int dwellTimeMs)` — fixed the Task 16 call (was a non-existent `dwellTimeMicroseconds:` param passing µs as ms).
- **`DateTimeOffset.ToUnixTimeMicroseconds()` does not exist** — replaced with `ToUnixTimeMilliseconds() * MathConstants.MicrosecondsPerMillisecond` (Task 17), matching `MouseGazeProvider`.
- **Exercise motion used absolute timestamps**; exercises assume a 0-based clock (`SmoothPursuitExercise` would be stuck in figure-8). The exercise window now feeds **elapsed** µs to `getTargetAt`/`recordGaze` off a single wall clock (Task 17).
- **Settings UI used a non-existent API** (`SettingsTab`, `SettingItemViewModel.Toggle/.Slider`): rewritten to the real `SettingsTabViewModel(name, symbol, items)` + `SliderSettingViewModel`/`ToggleSettingViewModel` ctors (Task 20).
- **Scheduler active-clock leaked away/paused gaps** onto the active total (first sample after a gap added the whole gap): fixed by advancing the inter-sample baseline on every call; added two regression tests (Task 13).
- **`IsClickThrough` set via XAML attribute** (it is `init`, read in `OverlayWindow.OnSourceInitialized`): now set in the code-behind ctor like `ManualSelectionOverlayWindow` (Tasks 16/17).
- **`async void OnBreakDue` had no catch**: added one (an unobserved throw would crash the process) (Task 15).
- **Pointless `out` param** on `ShowExerciseAsync`: dropped; the method returns `Task` and the service scores via `exercise.Complete()` (Task 14).
